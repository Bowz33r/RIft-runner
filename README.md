# Rift Runner — Neon Survival

A fresh arcade survival game built with vanilla HTML, CSS and JavaScript. No server or paid assets required.

## Play locally
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `game.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the URL.

## Controls
- A/D or left/right arrows: change lanes
- Space/W/up: jump
- Shift: phase dash
- Esc: pause
- Touch: swipe left/right to move; tap to jump

Collect shards to level up and choose upgrades. Your best distance is saved locally in your browser.

## Monetization
This build is a free prototype with no crypto paywall. For a paid release, consider a free demo plus optional cosmetic packs/supporter edition and use a reputable payment processor with clear pricing, refund terms and age-appropriate safeguards. Avoid selling gameplay power or charging crypto just to continue a run.

## Prototype status
Playable arcade loop, upgrades, score, collision detection, mobile touch controls and local best-score saving. Online accounts, global leaderboards, audio polish, controller support and cloud saves can be added later.
